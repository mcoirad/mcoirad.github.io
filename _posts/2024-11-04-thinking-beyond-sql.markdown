While thinking through a bunch of things related to data engineering with data warehouses, I decided to note some things and turned it into an article.

[I posted it on Medium, you can access the full text there.](https://medium.com/@macieiramitchell/thinking-beyond-sql-when-dbt-is-not-the-answer-317eee5a56a5)

In summary I noted my frusterations with DBT and its limitations. It is still a good tool but I don't think it is a great data engineering tool. It is a great analytics tool though, if that makes sense. But following SWE practices with feel to some degree feels like you are fighting with it. But it isn't unique in that case.

As a data engineer I like [SQLMesh](https://sqlmesh.com/) a lot more and will be following that ecosystem with a lot of interest.
