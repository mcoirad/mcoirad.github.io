## Sprite Jewelry EP

<iframe style="border: 0; width: 350px; height: 350px;" src="https://bandcamp.com/EmbeddedPlayer/album=3692447939/size=large/bgcol=ffffff/linkcol=0687f5/tracklist=false/transparent=true/" seamless><a href="https://spritejewelry.bandcamp.com/album/sprite-jewelry-ep">sprite jewelry EP by sprite jewelry</a></iframe>

Cleaning up and backing up an old laptop I found some old music of mine, very much in a similar style to my recently released album.

I went ahead and made a separate release for it on bandcamp.

It was fun drawing the album art again in a PC98 style. Once again I'm pretty happy with how it came out although I am already recognizing some flaws in it lol. I've put a lot of time into figure drawing the past year and I'm glad that it is starting to show.

I think next I will start to focus on drawing game assets for the games I've been working on. Some will need to be animated which will be a new challenge.
